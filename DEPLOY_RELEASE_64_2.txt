BiteBoss v64.2 RELEASE

출시 직전 UI/문구/상태 정리 통합본.

반영:
- 콘솔 [BiteBoss] build 로그 제거
- window.__BITEBOSS_BUILD__ 내부 값은 유지
- Rank / Players / Territory 등 사용자 화면 한글화
- 하단 내비게이션: 홈 / 도전 / 순위 / 프로필
- 매장 상세 중복 매장명 제거: 모달 타이틀 '매장 상세'
- 사용자 순위에서 내 순위 고정 요약
- 순위/크루/점령지 문구 한글화
- 프로필 로그인/계정/보스/크루/유효 방문/방문 기록/로그아웃 한글화
- 개인정보/고객지원 동일 톤 유지
- 공통 로딩/빈 상태/오류 상태 디자인
- QR 스캔/사용자 프로필 오류 문구 한글화
- 모달 X 및 주요 터치 영역 최소 44px
- 계정 삭제/로그아웃은 설정 하단에서 낮은 위계
- 기존 v64.1 매장 상세 정렬 및 v64.0 도전 목록 구조 유지
- Supabase 변경 없음

수동 확인:
window.__BITEBOSS_BUILD__
=> "64.2"

콘솔에 [BiteBoss] build 64.2는 자동 출력되지 않습니다.
