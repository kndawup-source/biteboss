BiteBoss v64.8 RELEASE

중복 보스 상태 문구 정리.

변경:
- 매장 목록의 '현재 보스' 라벨 제거
- 매장 목록의 '현재 보스 없음' 제거
- 매장 목록의 '내 점령지' 제거
- 점령 매장은 반반 원형 이미지 + 보스 닉네임만 표시
- 미점령 매장은 보스 관련 텍스트를 표시하지 않음
- 내 점령지라도 보호 중일 때는 '보호 N분 남음'만 유지
- 상세 화면의 '현재 보스' 라벨 제거
- 상세 화면에서 보스가 없을 때 별도 빈 보스 블록 제거
- 상세 '내 점령지' 상태 배지 제거
- 보호/파워부족/재도전대기처럼 실제 판단에 필요한 상태만 유지
- 홈의 '현재 보스 없음' -> '보스 기록 없음'
- 점령 현황 내부 '현재 보스' -> '보스'
- v64.7 반반 원형 이미지 및 자동 점령 기본 안내 제거 유지
- v64.6 로그인 중복 안내 제거 유지
- v64.5 PC 하단 메뉴 수정 유지
- v64.4 사용자 프로필 정리 유지
- v64.3 로그인 사용자 순위 ID 수정 유지
- Supabase 변경 없음

확인:
window.__BITEBOSS_BUILD__
=> "64.8"
