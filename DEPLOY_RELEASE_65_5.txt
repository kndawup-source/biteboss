BiteBoss v65.5 RELEASE

매장 상세 보스 상태 표현 수정.

변경
- 보스 본인에게는 짧은 '현재 이 매장의 보스' 결과 라벨을 제거
- 대신 아래 안내 문구를 한 번만 표시:
  '현재 이 매장의 보스입니다 · 다시 방문하면 방어력이 유지됩니다.'
- 위 문구는 왼쪽 정렬
- 보스 본인에게 빈 power result 행은 렌더링하지 않음
- 이미 내가 점령한 매장에서 '도전 가능' 배지가 나오던 오류 수정
- 내 매장은 보호 중일 때만 '보호 중' 상태 배지 표시
- 다른 사용자가 점령한 매장은 기존대로 '도전 가능' 표시 가능
- canChallenge 자체도 기존대로 보스 본인은 false 유지

DB
- v65.5 새 DB 변경 없음
- v65.3 이상 SQL이 이미 적용돼 있다면 SQL 재실행 불필요

확인
window.__BITEBOSS_BUILD__
=> "65.5"
