BiteBoss v65.2 RELEASE

추가
- 크루 개설자가 크루 프로필에서 크루명을 변경할 수 있음
- 크루명 변경은 크루 기준 월 1회
- 마지막 변경 시각 + interval '1 month' 이후 다시 변경 가능
- 리더가 바뀌어도 크루 자체의 변경 쿨다운은 유지
- 2~30자
- 대소문자/연속공백 정규화 기준 중복명 방지
- 이름 레지스트리와 실제 크루명은 한 트랜잭션에서 변경
- 같은 이름 입력은 변경 처리하지 않음
- 대소문자만 바꾸는 변경도 월 1회 변경으로 계산
- UI에 다음 변경 가능 시간 표시

크루 프로필
- 이미지와 크루명을 한 화면에서 별도 관리
- 개인 프로필과 크루 프로필을 분리한 구조 유지

기존 유지
- v65.1 크루 이미지 Storage 저장 수정
- 도전 목록: 매장/점령자 50:50
- 매장 상세 상단: 매장 이미지 100%
- 매장 상세 하단: 크루 이미지 우선 점령자 프로필

적용
1. Supabase SQL Editor에서 BITEBOSS_V65_2_CREW_PROFILE.sql 실행
2. 마지막 verification 3개 모두 true 확인
3. v65.2 웹 배포

확인
window.__BITEBOSS_BUILD__
=> "65.2"
