BiteBoss v65.7 RELEASE

사용자 프로필 모달에 개인 프로필 이미지 추가.

변경
- 순위에서 사용자를 눌러 여는 '사용자 프로필' 상단에 개인 프로필 이미지 표시
- 이미지 + 닉네임 + 크루명을 하나의 사용자 identity 영역으로 구성
- 개인 프로필 이미지가 없을 때만 첫 글자 fallback
- 순위 카드의 personal avatar URL을 프로필 모달로 전달
- 기존 biteboss_player_profile RPC가 avatar_url을 반환하지 않는 경우에도
  순위에서 전달된 개인 avatar를 사용
- 크루 프로필 이미지는 이 화면에 사용하지 않음
- v65.6 개인 순위 이미지 구분 유지

DB
- 새 SQL 변경 없음
- v65.6 SQL이 이미 적용되어 personal_avatar_url이 정상이라면 웹만 배포

확인
window.__BITEBOSS_BUILD__
=> "65.7"
