BiteBoss v65.9 RELEASE

프로필 페이지 위계 재수정.

로그인 사용자
- 상단은 개인 프로필만 표시: 개인 이미지 + 닉네임
- 크루명은 상단 닉네임에서 제거하고 크루 섹션에서만 표시
- 매장 추가는 상단에서 제거하고 설정 영역으로 이동
- 보스 상태를 가운데 큰 블록에서 좌측 정렬 한 줄 상태로 변경
  예: 보스 상태 · 활동 중                         1곳
- 보스 상태의 불필요한 진행바 제거
- 핵심 수치 4개는 한 줄 compact 유지
- 크루 순서: 크루 프로필 -> 멤버/점령지 -> 멤버 목록 -> QR 초대/해산
- 전투 기록 / 방문 기록 간격 및 제목 위계 통일
- 방문 기록 count '1 place' -> '1곳'

비로그인 사용자
- 개인 이미지/게스트명
- 로그인 안내
- 로그인 / 계정 만들기
- 최소 정보:
  둘러보기 = 주변 매장 · 순위
  로그인하면 = 점령 · 크루 · 기록 저장
- 의미 없는 0값 게임 통계/크루/기록은 숨김
- 개인정보 처리방침 / 고객지원은 비로그인 상태에서도 유지

DB
- 변경 없음
- SQL 재실행 불필요
