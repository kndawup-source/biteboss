BiteBoss v64.7 RELEASE

점령 매장 이미지 상태 표현 + 자동 점령 안내 문구 정리.

변경:
- 미점령 매장: 기존 원형 매장 이미지 100%
- 점령 매장: 원형을 세로 50:50으로 분할
  · 왼쪽: 매장 이미지
  · 오른쪽: 현재 보스 프로필 이미지
- 매장/보스 이미지가 없으면 각 절반에 첫 글자 fallback
- 목록과 매장 상세 모두 동일한 반반 원형 규칙 적용
- 중앙에는 얇은 1px 분리선만 사용
- '현장 2:00 체류 시 자동 점령' 기본 안내 문구 제거
- 상세의 '매장 근처에서 2:00 체류하면 자동으로 도전합니다.' 문구도 제거
- 실제 자동 점령이 진행 중일 때의 남은 시간 상태는 유지
- 거리 밖 / GPS 정확도 확인 등 실제 상태 메시지는 유지
- 우측 로그인/QR 도전 등 실제 행동 버튼은 유지
- v64.6 중복 로그인 안내 제거 유지
- v64.5 PC 하단 메뉴 수정 유지
- v64.4 사용자 프로필 정리 유지
- v64.3 로그인 사용자 순위 ID 수정 유지
- Supabase 변경 없음

window.__BITEBOSS_BUILD__
=> "64.7"
