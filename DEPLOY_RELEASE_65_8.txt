BiteBoss v65.8 RELEASE

프로필 페이지 위계 전면 정리.

게스트
- 프로필 이미지 / 게스트명 / 로그인 안내만 우선 노출

- 의미 없는 0 값의 보스 상태, 레벨/보스/크루/유효방문, 크루 없음, 전투/방문 기록, 설정 영역은 숨김
- 로그인 전 화면을 짧고 명확하게 정리

1. 개인 프로필
2. 계정 액션
3. 보스 상태
4. 레벨 / 보스 / 크루 / 유효 방문 핵심 수치
5. 크루
6. 전투 기록
7. 방문 기록
8. 설정/지원
