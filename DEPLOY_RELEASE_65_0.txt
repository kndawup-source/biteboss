BiteBoss v65.0 RELEASE

핵심 수정
- 도전 목록의 점령 매장:
  매장 이미지 + 점령자(크루 우선) 이미지를 원형 50:50으로 유지.
- 매장 상세 상단:
  반반 이미지를 사용하지 않고 매장 프로필 이미지만 100% 표시.
- 매장 상세 하단 보스 영역:
  점령자 프로필 이미지를 그대로 유지.
  크루 프로필 이미지가 있으면 크루 이미지를 우선 표시하고,
  없으면 개인 프로필 이미지를 표시.
- 목록 카드 하단의 중복 점령자 프로필/닉네임 행은 계속 비노출.

크루 프로필 이미지
- 크루 개설자가 업로드/삭제 가능.
- 일반 멤버는 보기만 가능.
- 기존 biteboss-avatars 버킷 재사용.

중요

v65.0의 BITEBOSS_V65_0_CREW_AVATAR.sql을 Supabase SQL Editor에서 먼저 실행해야 합니다.
