BiteBoss v64.4 RELEASE

사용자 프로필 모달 위계/한글화 정리.

변경:
- 모달 상단 중복 닉네임 제거: 상단 제목은 '사용자 프로필'
- PLAYER -> 사용자
- Level -> 레벨
- Boss -> 보스
- Crew -> 크루
- HEAD TO HEAD -> 맞대결 전적
- 0 battles -> 0전
- You won -> 내 승리
- They won -> 상대 승리
- Became Boss -> 보스 점령
- Lost Boss -> 보스 상실
- Became Crew -> 크루 합류
- Defense win -> 방어 성공
- Boss activity -> 보스 활동
- 최근 알림 -> 최근 기록
- 기록 수는 'N건'

위계:
1. 닉네임
2. 크루/개설자
3. 레벨 · XP · 보스 · 크루 핵심 수치
4. 맞대결 전적
5. 최근 기록

간격:
- 이전 uniform gap 제거
- 프로필/스탯 간 16px
- 주요 섹션 간 28px
- 맞대결 행 58px
- 최근 기록 행 60px
- 모바일 터치/가독성 유지

v64.3 로그인 사용자 순위 ID 수정 유지.
콘솔 build 로그 제거 유지.
Supabase 변경 없음.

확인:
window.__BITEBOSS_BUILD__
=> "64.4"
