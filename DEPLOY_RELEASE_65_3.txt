BiteBoss v65.3 RELEASE

프로필 / 크루 상태 점검 및 구분 보강.

수정
- 게스트 상태 'No crew' -> '크루 없음'
- 게스트의 크루 만들기 버튼 -> '로그인 후 크루 만들기'
- 게스트가 해당 버튼을 누르면 로그인 화면으로 연결
- 크루 영역 Founder / Member / Transfer / Invitations / Join / Decline 등 잔여 영어 한글화
- 크루 상세 Territories / Members 한글화
- 개인 프로필 수정 Profile / Nickname / Photo / Save 한글화
- 크루 초대 화면 잔여 영어 정리

개인/크루 이미지 구분
- 개인 순위는 반드시 biteboss_profiles.avatar_url 개인 프로필 이미지만 사용
- 크루 프로필 이미지는 개인 순위에 사용하지 않음
- 내 순위 고정 영역에도 개인 프로필 이미지 표시
- 크루 순위 데이터에는 크루 avatar_url을 별도로 반환
- 점령 매장에서는 기존 규칙대로 크루 이미지 우선

적용
1. Supabase SQL Editor에서 BITEBOSS_V65_3_PROFILE_CREW_AUDIT.sql 실행
2. 마지막 verification 3개 true 확인
3. v65.3 WEBROOT 배포

확인
window.__BITEBOSS_BUILD__
=> "65.3"
