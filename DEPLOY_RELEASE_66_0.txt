BiteBoss v66.0 RELEASE

크루 / 주변 크루 순위 프로필 이미지 추가.

크루 탭
- biteboss_game_rankings_v656의 조직 avatar_url 사용
- 크루 프로필 이미지 원형 46px 표시
- 이미지 없을 때만 크루명 첫 글자 fallback

주변 크루 탭
- 신규 RPC biteboss_local_crew_rank_v660
- Nearby Crew 응답에도 organizations.avatar_url 추가
- 크루 탭과 동일한 원형 프로필 UI 사용
- 개인 프로필 이미지는 사용하지 않음

이미지 구분 기준
- 사용자 순위 = 개인 프로필 이미지
- 사용자 프로필 = 개인 프로필 이미지
- 크루 순위 = 크루 프로필 이미지
- 주변 크루 = 크루 프로필 이미지
- 점령 매장 = 크루 이미지 우선

적용
1. Supabase SQL Editor에서 BITEBOSS_V66_0_CREW_RANK_AVATAR.sql 실행
2. local_crew_rank_v660 = true 확인
3. v66.0 WEBROOT 배포

확인
window.__BITEBOSS_BUILD__
=> "66.0"
